## Findings

- Fixed during review: backslash rejection originally happened inside command substitution, which printed the right error but did not propagate exit code reliably under the shell used here. Rejection is now performed before normalization at write-side command boundaries.
- Fixed during review: EXIT trap cleanup flattened some error statuses in this shell. The trap now preserves the original status.
- Fixed during review: cloned subproject commits in tests relied on global Git identity. `tests/helper.sh` now exports author/committer identity so cloned repos can commit consistently.
- Fixed during review: two tests created bare outer remotes without setting `HEAD` to `main`, which failed in environments whose bare default is `master`.

## Confusion Checks

- Dry-run fetch semantics are documented in README and technical notes: dry-run does not run `git fetch`; it uses `git ls-remote` where possible and reports unknown otherwise.
- Path canonical form is documented in README path-safety notes; backslash paths are refused with exit code 2.
- Skill source location is now `.agents/git-nest/SKILL.md`; `skills/git-nest/SKILL.md` was removed.
